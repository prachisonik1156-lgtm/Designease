🎓 College Project

Designing Made
Simple for All

DesignEase is a final year college project — a web-based platform where anyone can create stunning posters, resumes, and presentations using templates and AI, no design experience needed.

🎯

Our Goal

Build a practical, easy-to-use design tool that solves a real problem — making design accessible for students and beginners.

📚

Academic Purpose

Developed as part of our final year academic project, applying full-stack web development concepts learned during our course.

⚙️

What We Learned

Flask backend, SQLite database, REST APIs, AI integration, admin dashboards, and real-world project planning.

Core Features

What DesignEase Offers

Three main features that make up the platform, each built and integrated by our team.

🖼️

Template Library

A collection of ready-to-use templates for posters, resumes, and presentations. Users can browse, select, and download — all managed through the admin panel.

🤖

AI Presentation Generator

Users type a topic and the AI automatically generates a complete, structured presentation. Powered by an AI API and managed by the admin with on/off controls.

🛡️

Admin Dashboard

A full control panel for managing users, templates, AI settings, and viewing real-time usage reports with charts and analytics.
